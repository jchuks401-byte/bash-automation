# Bash Automation

An interactive Bash scripting project developed while learning Linux, Shell scripting, and Git.

## Overview

This project demonstrates practical Bash scripting concepts used in Linux administration and IT automation.

## Features

- Interactive menu system
- Say Hello
- Check Age
- Show Current Date
- Calculator
- Even or Odd Checker
- Guess the Number Game
- Input Validation
- Loop-based menu navigation

## Technologies

- Bash
- Linux (Ubuntu)
- Git
- GitHub

## Skills Demonstrated

- Shell scripting
- Functions
- If/elif/else statements
- While loops
- User input validation
- Problem solving
- Version control with Git

## Future Improvements

- Convert menu to a case statement
- Add arrays
- Add file handling
- Create system administration automation scripts
- Add backup and monitoring scripts
